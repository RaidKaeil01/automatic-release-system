## 内容风格差异

### 详细模式特点

- 每章包含完整的原理讲解、寄存器/HAL 库配置说明
- 代码附逐行注释，运行结果有详细说明
- 包含调试技巧和常见错误排查
- 适合初学者系统学习

### 精简模式特点

- 聚焦核心配置和关键代码片段
- 省略基础概念和过多原理铺垫
- 代码以核心实现为主，注释简洁
- 适合有基础的开发者快速上手
